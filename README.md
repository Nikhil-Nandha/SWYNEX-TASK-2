# StudySprint — Student Study Planner

A mobile-responsive student productivity app built with **HTML, CSS and vanilla JavaScript**. No framework or build step is required.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser. For a local server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Primary screens

- **Welcome / Login:** simple demo entry screen.
- **Dashboard:** study overview, summary cards, today's tasks and subject progress.
- **My Subjects:** view subjects and add new subjects.
- **Task Manager:** add tasks, assign a subject and due date, filter tasks, and mark tasks complete.
- **Progress Tracker:** task completion rate, study streak presentation and progress by subject.

## Features

- Responsive desktop and mobile layouts with bottom navigation on small screens.
- Persistent demo data using browser `localStorage`.
- Interactive task completion, task creation, subject creation and task filters.
- Accessible labels and button names for key controls.

## Notes

This is a front-end demo. Login is not connected to an authentication service, and data is stored locally in the browser rather than on a server.
